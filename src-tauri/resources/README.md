# 内置模型参数字典说明

```
# ============================================================================
# ModelScout 内置模型参数字典
# ============================================================================
#
# 【用途】
# 探测上下文窗口 / 单次输出上限时的**第一优先级数据源**。
# 命中本字典的模型无需发起「超大 max_tokens」请求，既省时间又省额度。
#
# 【字段说明】
#   - matchPatterns : 模型 ID 的匹配模式，支持三种语法
#                       * 精确串（无通配符）      → 完全相等匹配
#                       * `xxx*`                 → 前缀匹配
#                       * `*xxx*`                → 包含匹配
#                     数组内按**从上到下**顺序匹配，取第一个命中项。
#   - contextLimit  : 上下文窗口上限（token）
#   - maxOutputLimit: 单次最大输出（token）
#   - note          : 备注，会在前端 tooltip 中展示来源说明
#
# 【维护提示】
# ⚠️ 本字典中的数值由模型厂商公开文档整理，**存在时效性风险**。
#    当你发现探测结果与实际不符时，请直接编辑本文件后重启应用。
#    所有数值均需对照厂商最新官方文档核对（见交付报告「待人工确认」章节）。
#
# 【重要：匹配顺序】
# 更具体的模式必须排在更宽泛的模式**之前**，否则会被宽泛规则先截获。
# 例如 `gpt-4o-mini*` 必须排在 `gpt-4o*` 之前。
# ============================================================================
```
